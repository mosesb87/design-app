How the prototypes were built

Server-rendered HTML fetched with a self-identifying audit user agent (CommerceIntelligenceLab-Audit/1.0), 1.5 s between requests; rendered checks in Chrome; PageSpeed Insights run in the browser on 2026-09-10 08:53 EDT. The category’s three routes were read as served: the parent lists 30 products, Hospital Beds 21, Stretchers 12; the union is 34 distinct products because assignment differs by route. Every filter page under the category was fetched so each product’s current filter values are the ones the storefront actually holds, not guesses. Product-page specifications were read for capacity and dimensions. Nothing was inferred from analytics, because none were available.
