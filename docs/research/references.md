# Motion and art direction research: 11 reference sites for Mousa Batarseh's portfolio

**Research date:** 2026-09-26. **Method:** I pulled page text through Exa web_fetch, plus third-party sources (Awwwards, FWA, CSS Winner, Codrops, A1 Gallery, studio case studies, LinkedIn posts). No site was viewed live in a browser. So any motion described below comes from a report or is marked as my inference, never from direct viewing.

**Tags:** [TEXT] = fetched page text or structure · [REPORTED: source] = third-party or studio statement · [INFERRED] = my interpretation.

## Cross-cutting principles
1. **Receipts as interface.** Counts, dates and sources are structured, sortable data (Hon Tran's table, Aino's 001–038, Driftime's stats). For Mousa, every number carries its "counted on" date and source link. [INFERRED from TEXT/REPORTED]
2. **Show the system, not the screenshot.** Aino's "How it's built", Wild's file tree and slowed-down recordings, monolayer's CLI. Mousa's cases should include a spec list plus a short real recording of the tool or workflow. [INFERRED]
3. **One motion language, written as tokens.** Shared eases, a duration scale and reusable reveal components (Hon Tran, S25's GSAP library, Trionn's `BlurTextReveal`). Decide 3–4 eases and 3 durations, then ban one-off timings. [REPORTED → INFERRED]
4. **A process spine as the main scroll story.** Numbered stages appear on monolayer, Wild, Coinsetters and Twohands. Mousa's pinned sequence could be his real ops loop, e.g. audit → fix → verify → monitor. [INFERRED]
5. **Drive many effects from one state value.** Trionn maps scroll, hover and click into one normalised value. Use one progress value to move a diagram, a counter and a caption together, so motion stays explainable and easy to debug. [REPORTED → INFERRED]
6. **Calm base, one signature.** Coinsetters' rainbow flow, DDDx's palette light, monolayer's system visual. Put expression in one recurring motif and keep everything else quiet. [REPORTED → INFERRED]
7. **The performance budget is a brand claim.** Aino publishes 30kb JS and Lighthouse 100; Driftime admits carbon weight; Basilico prioritises mobile. For an SEO and ops person, publishing and meeting the site's own budget *is* the proof. [REPORTED → INFERRED]
8. **Candour sections.** "Lessons & Setbacks" (Driftime), "Hopeless at" (Wild), "Who we're not for" (Trionn), "a better fit for a product team" (Hon Tran). Dated findings should include misses. [TEXT]
9. **Honest attribution.** Hon Tran's owns-vs-owned table. Mousa should mark per project what he did personally, what he did with a team, and what the client did. [TEXT → INFERRED]
10. **Utility sections deserve the craft.** DDDx's schedule, Twohands' QA list, monolayer's boundary table. A filterable findings log or changelog can be the most polished component on the site. [REPORTED → INFERRED]
11. **Reduced motion is a designed state, not a kill switch.** Trionn slows motion and gives mobile its own logic; Hon Tran honours `prefers-reduced-motion`. Also design the RTL state: mirror direction-dependent reveals for Arabic. [REPORTED → INFERRED]
12. **Text splitting must stay crawlable.** Hon Tran, Trionn and Driftime all leak split or duplicated characters into extracted text. [TEXT]
    - Keep the full string in the DOM with an `aria-label` or a visually hidden copy.
    - For Arabic, split by word or line, never by character, because splitting breaks letter joining. [INFERRED]

## Anti-patterns to avoid
- **Hold-to-blast 3D logos, sound-on interactions, draggable mascots, pluckable footers (Trionn).** Instantly recognisable as borrowed, and against his voice.
- **ASCII or character-physics "text as medium" (Aino, 2026).** It is Aino's signature right now, and it doesn't work with Arabic script.
- **Pixel, dither and SF Mono "AI studio" styling (Wild)** and **dark Geist big-type with marquee testimonials (Twohands / Saaspo genre).** Both read as templates in 2026.
- **Rainbow gradient flows, sticker 3D, crypto energy (Coinsetters).**
- **Halo metrics ("$500M+ raised with our design").** Any number Mousa shows needs a scope, a date and a mechanism.
- **Trophy walls as the hero.** He should lead with before/after metrics and artefacts, not badges he doesn't need.
- **Preloaders and intros that gate content, WebGL heroes, scroll-hijacking smooth scroll without an opt-out.** SEO, Core Web Vitals and accessibility costs that someone evaluating an SEO specialist will notice.
- **Autoplay video walls.** Follow Hon Tran's one-active-video rule.
- **Event-style staleness (DDDx).** Undated "current" content that ages visibly. Every claim should carry a date.

## PROBED — measured in a real browser (GitHub Actions, Chromium, 2026-09-26)

Objective measurements from `scripts/capture/probe.mjs` (no imagery stored). Heuristics, stated plainly: *scroll-driven elements* counts elements whose transform, opacity or clip-path differs between two scroll positions ¼ viewport apart at six points down the page — marquees and looping animations also count, so treat it as an indicator, not a census. *Pinned candidates* are tall, non-fixed elements whose position did not move while scrolling. Transfer size is what loaded before the probe finished (lazy media may add more).

**What the measurements add to the written analysis**

- **Reduced motion is often not honoured.** Coinsetters (827 → 826), Trionn (229 → 226), S25 (124 → 119) and Twohands (69 → 87) keep essentially all scroll-driven motion when the visitor asks for less. Mousa's own v1 (157 → 1) and v2 (142 → 2) do honour it — the new site must too, and does (reduced motion renders static compositions).
- **Weight ranges 60×.** monolayer (141 KB) and Coinsetters (129 KB) load light; Wild (8.9 MB), Hon Tran (7.7 MB) and Trionn (2.9 MB) are heavy before any interaction. For an SEO and performance specialist the light end is the credible one; the new site publishes its own weight in the footer.
- **GSAP + ScrollTrigger + Lenis is the common stack** (monolayer, Coinsetters, Trionn; Lenis alone on DDDx, Driftime, Hon Tran). The new site uses the same proven tools — the distinction has to come from the concept, not the library.
- **Mono faces are the 2026 default for metadata** (DM Mono, JetBrains Mono, Martian Mono on Trionn — confirmed). The new site uses Azeret Mono, which none of the references load.
- **Custom cursors appear on 4 of 11** (Coinsetters, Driftime, Trionn, plus class-name matches). The new site keeps the native cursor and only adds a registration target over plates — no hidden cursor.
- **Only Driftime uses View Transitions.** Cross-document View Transitions remain a real differentiator for the plate-to-case-study morph.
